# Muretto

Landing page del proyecto residencial **Muretto** (Temozón Norte, Mérida, Yucatán), un desarrollo de Desarrolladora Calume.

## Stack

- Next.js 14 (App Router, TypeScript)
- Tailwind CSS con la paleta de marca oficial de Muretto (extraída del brochure): navy `#00283E`, camel `#B18C6E`, crema `#EAE3DE`
- Sin backend: el formulario de contacto abre WhatsApp con los datos prellenados

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm start
```
